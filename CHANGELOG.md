# Changelog

All notable changes to the SwiftFix Plumbing Services website are documented in this file.

## [Unreleased] - 2026-05-26

### Added
- Created a responsive **mobile-first navigation bar** with hamburger menu and sticky header.
- Added **SEO enhancements** including unique page titles, meta descriptions, keywords, and optimized image alt text.
- Implemented a **live search filter** on the services page for instant service lookup.
- Added a responsive **gallery page** with **lightbox modal** and keyboard navigation controls.
- Built an accessible **service enquiry form** with full validation and submission feedback.
- Added a responsive **Google Map embed** for Pretoria location and service area emphasis.
- Updated the homepage, about page, services page, enquiry page, contact page, and created gallery page for consistent branding.

### Changed
- Converted the site to semantic **HTML5 structure** with clear `header`, `main`, `section`, and `footer` sections.
- Reworked CSS for polished professional design, consistent spacing, responsive footer columns, and refined navigation styling.
- Implemented Part 2 responsive styling with breakpoints, relative units, and layout adjustments for tablet and desktop.
- Added responsive image optimisation with `srcset` and `sizes` for hero, service, enquiry, and gallery assets.
- Enhanced JavaScript to support navigation toggle, search filtering, form validation, gallery lightbox, and keyboard accessibility.

### Documentation
- Updated `README.md` with project overview, features, responsive design details, SEO improvements, and form validation notes.
- Added `CHANGELOG.md` to record development progress and feature delivery.
