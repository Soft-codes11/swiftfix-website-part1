# Changelog

All notable changes to the SwiftFix Plumbing Services website are documented in this file.

## [Unreleased]

### Updated
- Refreshed the README to reflect the current website structure, implemented features, and actual page behaviour.
- Clarified that the contact form is present in the layout but does not currently include custom JavaScript validation or submission handling.
- Confirmed the current scope of the live site: homepage, about, services search, gallery lightbox, enquiry validation, contact page map, and shared responsive navigation/footer.

## [Release] - 2026-04-29 (Part 1: Requirements + HTML structure)

### Added
- Documented the website requirements and started implementation.
- Created initial folder structure and began building page files (homepage, about, services, enquiry, contact, gallery).
- Added basic semantic page layout and wiring for the shared header/footer navigation.

### Changed
- Introduced the core HTML structure (`header`, `main`, `section`, `footer`) across the site.

## [Release] - 2026-05-26 (Part 2: CSS/UX + interactive features)

### Added
- Created a responsive mobile-first navigation bar with hamburger menu and sticky header.
- Added SEO enhancements including unique page titles, meta descriptions, keywords, and improved image alt text.
- Implemented a live search filter on the services page (services.html) for instant service lookup.
- Added a responsive gallery page with lightbox modal and keyboard navigation controls (gallery.html + js/script.js).
- Built an accessible service enquiry form with full client-side validation and submission feedback (enquiry.html + js/script.js).
- Added a responsive Google Map embed for Pretoria location on the contact page (contact.html).
- Updated/standardised content across the homepage, about page, services page, enquiry page, contact page, and gallery page.

### Changed
- Reworked CSS for polished professional design, consistent spacing, responsive footer columns, and refined navigation styling.
- Implemented responsive Part 2 styling with breakpoints, relative units, and layout adjustments for tablet and desktop.
- Enhanced JavaScript to support navigation toggle, search filtering, form validation, gallery lightbox, and keyboard accessibility.

### Documentation
- Updated README with project overview, features, responsive design details, SEO improvements, and form validation notes.
- Added CHANGELOG entries to record progress by milestone.
